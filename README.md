# Data-Cleaning-and-Visualization-of-Netflix-dataset

Data cleaning of a dataset found on Kaggle.

**Dataset**

Listings of movies and tv shows on [Netflix](https://www.kaggle.com/datasets/shivamb/netflix-shows).

Postgresql for data analysis. - [Click here for sql scripts](https://github.com/coco995o/Data-Cleaning-and-Visualization-of-Netflix-dataset/blob/main/netflix_data_cleaning.sql)

PowerBI for visualization. [Dashboard](https://app.powerbi.com/groups/me/reports/6fafcec4-6b9e-4b27-8ca5-fad063fdada4/bfa141e55d058cd02cb0?experience=power-bi)
